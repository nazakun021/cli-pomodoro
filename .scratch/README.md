# Local Planning Workspace

This directory contains feature-scoped planning and execution records used by the local issue tracker.

## Active efforts

- [Menu Bar Pomodoro](menu-bar-pomodoro/README.md) — ready-for-agent specification, resolved feature context, contracts, schemas, roadmap, and 18-ticket implementation DAG.

## Conventions

- Each effort owns one directory.
- `FEATURES.md` preserves grilling and design context.
- `SPEC.md` is the formal triaged specification.
- `ROADMAP.md` summarizes milestone and blocker topology without replacing live ticket status.
- `issues/` contains one ready-for-agent vertical slice per file.
- Repository-wide tracker and execution rules live under `docs/agents/`.
